# 브루미 이동 배경음

- 파일: `app/src/main/assets/audio/music/vroomie_trail.wav`
- 생성: `python3 scripts/generate_vroomie_bgm.py`
- 길이: 20초, 22,050 Hz, 모노 PCM16. 끊김을 줄인 반복 연주.
- 외부 음원, 샘플, 기존 곡의 멜로디를 사용하지 않고 사인파로 합성했다.
- 이 저장소에서 생성한 이 음원에는 CC0 1.0을 적용한다. 출처 표기 없이 수정·배포·상업적 사용 가능하다. 다른 앱 자산에는 적용하지 않는다.
- CC0 원문: https://creativecommons.org/publicdomain/zero/1.0/

본편 탐험 중 대사·효과음·마이크·악기 재생이 모두 없는 상태가 1.5초 이어질 때 10% 음량으로 반복한다. 부모 음소거, 내비 등의 오디오 포커스 상실, 휴식·종료 시 멈춘다. 화면에서 배경음만 별도로 끌 수 있다. 차량 하드웨어의 실제 출력 음량은 기기 설정에 따른다.
