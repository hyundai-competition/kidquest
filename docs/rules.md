# 작업 규칙

커밋하기 전에 이 문서의 규칙을 지킨다. 기계로 잡을 수 있는 것은 `scripts/check_repo.sh`가 막는다.

## 대회 규정

| 공고와 설명회 원문 | 우리가 지킬 일 |
|---|---|
| 「대표자·구성원의 성명, 연락처, 이메일, 소속은 기재하지 않습니다」 | 코드, README, 영상, 파일 속성에 실명과 학교를 넣지 않는다. |
| 「공유 링크와 첨부자료에도 개인정보·계정정보·개발자 실명이 노출되지 않도록 확인하세요」 | 커밋 이름은 역할 별칭만 쓴다. 제출 전에 링크를 로그아웃 상태로 확인한다. |
| 「제출한 서류에 기재한 내용이 사실과 다를 경우 선정이 취소될 수 있습니다」 | 안 만든 기능은 계획으로만 적는다. 기능 문장은 돌려 본 뒤에 쓴다. |
| 설명회 : 「전체 구조와 로직을 완벽하게 이해하고 2차 PT 기술 Q&A 때 직접 설명할 수 있어야 합니다」 | AI가 쓴 코드도 맡은 사람이 읽고 설명할 수 있어야 한다. |
| 「제3자의 작품 일부 또는 전부를 표절한 작품이거나 기 발표된 타 공모전 수상작」은 심사 제외 | 남의 앱, 기사, 동화의 문장과 그림을 옮기지 않는다. |
| 「APK 파일만 따로 제출하지 않고」 | 소스와 APK를 같은 저장소에 둔다. `apk/`의 파일명은 `팀명_앱이름_release.apk`다. |

## 개인정보와 비밀값

- 아이의 이름, 목소리, 위치를 저장하지 않는다. 기기에는 연령과 배지만 저장한다.
- 말을 듣는 기능은 부모가 동의했을 때만 켠다.
- 위치는 기기 안에서 좌표 비교에만 쓰고 밖으로 보내지 않는다.
- API 키, 서명 키, `.env`, `local.properties`를 올리지 않는다. 키를 앱에 넣지 않는다.
- 시험과 캡처에 실제 아이의 목소리나 얼굴을 쓰지 않는다.

## 아이 안전

- 창문 밖으로 몸이나 손을 내밀게 하지 않는다. 벨트를 풀어야 하는 임무를 만들지 않는다.
- 운전자를 부르거나 운전자에게 답을 물어보게 하지 않는다.
- 깜빡이로 보물이나 임무를 열지 않는다. 아이가 깜빡이를 켜 달라고 조르게 되고, 괜히 켠 깜빡이는 뒤차를 헷갈리게 한다. 갈림길 임무는 내비가 알려 준 갈림길을 지날 때 연다.
- 주행 중에는 움직이는 화면과 게임 조작을 넣지 않는다.
- 무서운 내용, 벌주는 말, 틀렸다고 혼내는 말을 쓰지 않는다.
- AI로 쓴 대사와 배경지식은 사람이 전부 읽고 고친다. 사실은 출처를 확인한다.

## 코드

- 기능별 폴더를 지킨다. 어디에 무엇을 두는지는 [structure.md](structure.md)에 있다.
- 파일 맨 위에 무엇을 하는 파일인지 주석으로 적는다. 왜 이렇게 했는지가 안 보이는 곳에도 적는다.
- 파일은 300줄을 넘기지 않는다. 함수는 40줄 안쪽을 권한다. 길어지면 나눈다.
- 차 SDK는 `car/`에서만 부른다. 판단은 `core/`에서만 한다.
- 사건과 명령을 바꾸면 `core/contract/`를 고치고 팀에 알린다.

## 커밋과 PR

- `main`에 직접 올리지 않는다. 브랜치를 만들어 PR로 합친다. 무료 플랜의 비공개 저장소는 잠금 기능이 없어서 약속으로 지킨다.
- 머지는 앱 통합 역할이 한다.
- 자기 할 일은 자기가 이슈로 연다. 기능 번호와 완료 기준을 적고 자기를 담당자로 지정한다.
- PR과 이슈에 자기 역할 라벨을 단다(`판단 로직·데이터`, `앱 통합`, `차량·내비 연결`, `화면·음성`, `시연·품질`). 사건, 명령, 에피소드 형식을 바꾸면 `약속 변경`도 단다. 이슈에는 `기본 시나리오`나 `여유 되면`도 단다.
- PR 본문에 `Closes #번호`를 쓰면 머지할 때 그 이슈가 닫힌다.
- 처음 한 번 아래를 실행한다. 별칭은 [structure.md](structure.md)에서 고른다.

```
git config user.name "kq-역할"
git config user.email "역할@kidquest.invalid"
git config core.hooksPath .githooks
```

- 팀원 이름을 막고 싶으면 저장소 폴더에 `.names.local` 파일을 만들어 한 줄에 하나씩 적는다. 이 파일은 올라가지 않는다.
