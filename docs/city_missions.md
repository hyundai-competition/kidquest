# 장소 설명과 체험 미션

사용자가 전달한 도시별 16개 교육 원고를 MissionEducation에 옮겼다. 원고 내용의 외부 출처 검수는 아직 하지 않았다. 그림은 코드로 그린 장식이며 실제 문화유산 사진·복원 도면이 아니다.

## 흐름

지도에서 장소 선택 → 교육 설명 화면 + 한국어 ON_DEVICE TTS → 미션 시작 → 체험 → 보물 조각 수와 완료 표시 → 지도 복귀.

- 설명 다시 듣기, 음성 멈추기, 설명 화면 복귀를 제공한다.
- 기존 엔진 대사는 체험을 여는 동안 부모 멈춤 사건으로 멈춘다. 체험 대사와 엔진 대사는 VoiceOutput의 같은 재생기를 사용한다.
- 체험 대사 ID는 screen_mission_ 접두사로 구분하고 엔진에 LineFinished를 보내지 않는다. 체험 완료는 기존 엔진의 임무 보상과 별도다.
- 닫기·미션 시작·다시 읽기·앱이 배경으로 이동할 때 설명 음성을 중단한다. 주행 규제 중에는 설명과 조작 화면을 숨기고 음성도 중단한다.
- 녹음 파일이 없어 TTS 실패 시 실제 녹음 대체는 아직 제공하지 못한다. 설명 글과 재생 상태는 남는다.

## 구현한 체험

| 방식 | 장소 | 구현 |
|---|---|---|
| 그림 수집 | 대릉원, 병산서원, 해양박물관, 고궁박물관, 종묘 | 목표 물건 여러 개 선택, 오답·중복 집계 방지, 도구 설명 |
| 별 잇기 | 첨성대 | 별 순서 터치 또는 연속 드래그, 연결선, 미취학 다음 별 강조 |
| 조각 배치 | 동궁과 월지, 봉정사, 창덕궁 | 조각 선택 후 같은 실루엣 자리 터치, 일부 오답 조각 |
| 특징 짝 맞추기 | 불국사, 하회마을, 경복궁 | 특징 카드와 대상 그림 짝 연결 |
| 순서 배열 | 월영교, BIFF 광장 | 정해진 순서로 조각·제작 단계 연결 |
| 자유 색칠 | 감천문화마을 | 팔레트 선택, 언덕 위 집 세 곳 색칠, 완료 후 다시 칠하기 가능 |
| 도개교 조작 | 영도대교 | 다리 올림·배 통과·다리 내림 단계, 장면 상태 변화 |

연령에 따라 별 4/7개, 배치 2/4개, 수집 목표와 순서 카드 개수가 달라진다. 초등 저학년은 완료 후 원고의 생각할 질문을 보여준다. 질문은 자동 채점하지 않는다.

## 후속 작업

- 원고에 있는 실제 사진 비교, 건축물 조각의 드래그 배치, 캐릭터 이동 애니메이션은 아직 없다. 배치는 터치 방식이다.
- 탈과 유물은 간략한 벡터 그림이다. 정확한 관찰 교육용 사진과 세부 유물 그림은 별도 확보가 필요하다.
- 종묘의 두 악기는 직접 합성한 임시 시연음을 사용한다. 실제 편종·편경 음색 재현이 아니며 화면에도 표시한다. 생성기는 scripts/generate_instrument_previews.py다.
- 실제 차량 위치에 따른 자동 시작과 본편 엔진의 지역 에피소드 연결은 후속 작업이다. 시연에서는 장소를 직접 누른다.
- 완료 내역은 ViewModel 메모리만 사용하며 새 탐험에서 초기화한다.

## 검증

- core/app 단위 테스트와 앱·기기 테스트 APK 빌드 통과.
- 16개 미션을 두 연령 설정에서 완료하는 규칙 시험, 잘못된 별 순서·빈자리 배치·중복 수집 시험 통과.
- Pleos 에뮬레이터 전체 기기 시험 10개 통과. 장소 설명의 실제 TTS 시작, 유물 오답·정답, 별 네 개의 연속 드래그, 두 조각 배치, 완료 표시와 지도 복귀를 포함한다.
- 차량 연결 시험은 음성 포트를 대역으로 분리했다. 해당 시험의 SDK 중단이 다음 실제 음성 시험에 영향을 주던 간섭을 제거하고 전체 시험을 재실행했다.
- 실제 문화유산 사진 비교와 모든 조작 화면의 세부 미감 검수는 완료 범위가 아니다.

## 읽기 쉬운 글자와 보상·마무리 화면

- 본문과 조작 글자를 주로 26~30sp, 큰 제목을 38~50sp로 키웠다. 명시하지 않은 Text·버튼·칩도 공통 Typography의 큰 글자를 사용한다.
- 장소 카드 높이와 지도 높이를 늘려 커진 이름을 담는다.
- 미션 성공 시 1.1초 동안 지도 조각이 커지고 빛 조각이 퍼지는 보상 모션을 한 번 보여준다. 모션은 주행 규제 분기에서는 구성하지 않는다.
- 성공 화면에서 조각 수, 배운 이야기, 다음 장소 이동과 완성한 미션 복습을 제공한다.
- 네 장소를 모두 마치면 여행 마무리 화면을 열 수 있다. 브루미의 한국어 인사, 네 장소 기록, 완성 지도 보기, 새 탐험 준비를 제공한다. 내비의 실제 목적지 도착과는 별개다.
- 완료 후 지도로 먼저 돌아가도 마무리 버튼으로 다시 열 수 있다. 새 탐험은 기존처럼 설정과 조각을 초기화한다.
- 큰 글씨의 네 도시 레이아웃 시험과 시작 설정 시험 통과. 연속 기기 실행에서는 장소 설명 TTS 초기화 대기가 한 번 실패했고, 해당 진행 시험을 단독 실행하여 네 장소 완료와 마무리까지 통과했다.

## 팀 결정 반영

주차·휴식 때의 액션 퍼즐에는 건너뛰기를 추가했고, 주행 중에는 세 보기 음성 퀴즈로 전환한다. 건너뛰기는 보상을 지급하지 않지만 여행 마무리를 막지 않는다. 최신 흐름과 실제 STT 검증 범위는 [voice_interaction.md](voice_interaction.md)에 적었다.
