# 와이퍼 임무 대본 v4 : 보물 지도 (`rain_map`)

**AI 초안을 사람이 읽고 고침.** (2026-11-12, 시연·품질)

11/7 회의에서 메인 스토리가 지역 역사 보물찾기로 바뀌어, v2의 별가루 구름을 보물 지도로 바꿨다. 값은 `app/src/main/assets/episodes/episode_demo.json`의 `rain_map`과 같다(#37, #52, #56, #57 기준). 목적지와 상관없이 모든 경로에서 쓰는 공통 임무다.

## 대사

| 순서 | 대사 |
|---|---|
| 브리핑 | 대장님, 보물 지도에 물방울이 묻으면 글씨가 흐려진대요. 지도 속 열쇠는 파란색이래요. |
| 사건 | (`wipe_drops` 소리) 쓱싹쓱싹! 와이퍼처럼 지도에 묻은 물방울을 닦았더니 글씨가 다시 보여요. |
| 질문 | 보물 상자 열쇠는 파란색일까요, 빨간색일까요? |
| 정답 | 맞아요, 파란색! 열쇠로 보물 지도 조각을 꺼냈어요. |
| 오답 | 열쇠 색은 파란색이었어요. 보물 지도 조각을 꺼냈어요. |
| 비가 안 올 때 | 오늘은 비가 안 와서 지도에 물방울이 없어요. 글씨가 잘 보여요! |
| 보상 | 보물 지도 조각 (`map_piece`) |

- 열리는 때 : 와이퍼 켜짐. 와이퍼가 없거나 안 켜면 120초 뒤 저절로 열린다.
- 정답 단어 : 「파란색」, 「파랑」

## 이렇게 정한 이유

- 실제 와이퍼가 앞유리 물방울을 닦는 모습을, 이야기 속 지도의 물방울을 닦는 장면으로 잇는다. 비 오는 날에는 운전자가 원래 와이퍼를 켜니 자연스럽다.
- 앱은 와이퍼를 켜지 않고 읽기만 한다. 운전 시야를 방해하지 않기 위해서다.
- 질문은 두 가지 중 고르는 말이라 어린아이도 답하기 쉽다. 브리핑에서 정답을 먼저 들려준다.
- 오답은 정답을 알려 주고 같은 보상을 준다. 혼내지 않는다.
- 「와이퍼처럼」은 비유라서, 와이퍼 없이 120초 뒤 저절로 열려도 어색하지 않다.

## 규칙 점검

- 운전자를 부르지 않는다 : 통과
- 벨트를 풀게 하지 않는다, 창밖으로 몸을 내밀게 하지 않는다 : 통과
- 혼내지 않는다 : 통과
- 화면을 보게 하지 않는다 : 통과. 말로 묻고, 화면 보기는 차가 서 있을 때만 쓴다
