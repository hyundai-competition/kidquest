# 차량 배경·BGM·언어 선택 연결

## 화면 확인

시작 화면은 **언어 → 경로 → 테마** 순서다. 연령 카드 대신 한국어 / English(12세 이상 권장)를 고른다. 이는 권장 표시이며 나이 검증이나 이용 제한이 아니다. 부모 동의 스위치는 첫 단계에서 선택하며, 꺼도 시작할 수 있다. 단계 이동·창 크기 변경·Activity 재생성 시 선택값을 ViewModel이 유지한다.

기존 연령 사건은 다른 모듈과의 호환을 위해 남겨 두고, 화면에서는 기본 연령만 전달한다. 주차용 보너스 퍼즐은 기존 한국어 콘텐츠를 유지하며 영어 화면에도 한국어 퍼즐임을 표시한다. 개발용 재생 패널도 한국어다.

## 와이퍼·방향지시등

- 실제 수집기와 재생 패널의 `WiperChanged`를 같은 표시 상태에 반영한다. 켜면 기본 비 배경, 끄면 원래 배경이다.
- 와이퍼만으로 실제 눈/비를 구분할 수 없다. 주차(P) 중에만 눈/비 연출을 바꿀 수 있다. 실제 날씨 조회 기능은 아니다.
- P이고 주행 규제가 없을 때만 낙하 애니메이션을 사용한다. D·R·기어 불명·주행 규제 상태는 정적 장식이다.
- `TurnSignalOn(LEFT/RIGHT)`는 브루미 캐릭터의 시선과 해당 쪽 방향등으로 표시한다. 와이퍼가 켜져 있으면 우산을 쓴 모습을 유지한다. 마지막 사건에서 약 3.5초 뒤 지운다(1초 Tick 해상도). OFF 사건이 없는 기존 계약에 맞춘 짧은 반응이며 실제 등 상태 표시를 대신하지 않는다.
- 깜빡이 효과음 `turn_tick_left/right`는 음성 출력에서 재생하지 않는다. 깜빡이로 임무를 열거나 보상을 주지 않는다. 갈림길 임무는 기존 내비 사건 기준이다.

현재 일반 화면에서는 재생 패널을 숨긴다. [시연 체험](showcase_mode.md)의 자동 와이퍼·좌우 반응 또는 실제 차량 콘솔로 확인할 수 있다. 기기 화면 테스트는 사건을 주입한 결과이며 실제 콘솔→SDK→화면의 전 과정 검증과 구분한다.

## BGM

[음원 설명과 사용 조건](audio/vroomie_trail.md). 외부 곡을 내려받지 않고 합성한 짧은 반복 연주다. 본편 FLYING 상태의 조용한 구간에만 재생한다. 대사·효과음·마이크·악기·부모 음소거·포커스 상실 시 중단한다. 배경음 버튼으로 별도 끌 수 있다. 실제 내비의 포커스가 전달되는지는 차량·내비 검증과 별개다.

## 영어 연결과 팀 작업 경계

언어 엔진 브랜치 `feature/language-engine`의 `LanguageSelected`, 언어별 에피소드 선택, 고정 영어 대사 구조를 로컬에 연결했다. 브랜치의 에너지 절반 안내는 이번 범위에 포함하지 않았다. 원격 PR을 머지하거나 수정한 것은 아니다.

`episode_demo_en.json`은 기존 한국어 대본의 14개 임무와 4개 목적지를 번역한 초안이다. 장소 좌표·임무/경로/보상 ID·신호·대기 시간은 동일하다. 기존 사실 출처를 보존했지만 새 영어 표현은 팀의 콘텐츠 검수가 필요하다. #60의 별도 영어 대본이 합쳐지면 이를 기준으로 조정한다.

한국어 TTS/STT는 `Locale.KOREA`, 영어 본편은 `Locale.US`를 사용한다. 한국어 보너스 퍼즐은 한국어 음성과 인식을 유지한다. 영어 번호 답변 one/two/three 등은 기존 번호 어댑터로 연결한다. 에뮬레이터의 실제 목소리 STT는 마이크 입력을 꺼 둔 기존 환경 제약 때문에 검증하지 않았다.

## 검증

- core·app 단위 테스트 및 Debug APK/테스트 APK 빌드.
- 영어 전체 대본의 ID·좌표·신호 일치와 14개 질문 보기 연결.
- Pleos ON_DEVICE 영어 TTS 정상 완료, 생성 BGM 실제 재생·중단.
- 언어 선택→영어 본편→번호 정답, 주차 눈/좌깜·주행 정적 눈/우깜, 창 크기·재생성·동의 유지.
- 뒤로가기·종료·비활성 보기 접근성, P 전용 놀이터 자동 닫힘, 기존 화면 답변과 결과 화면 회귀.

커밋·푸시 없이 로컬 변경으로 보관한다.

## 후속 화면 점검

- 영어 시작 화면의 언어 제목, 마이크 준비·실패 안내, 엔진 상태 문구와 보물 지도 접근성 설명의 번역을 보완했다.
- 한국어 놀이터를 열었을 때 음성 상태 패널까지 한국어로 유지한다. 본편과 전역 뒤로·종료는 선택 언어를 따른다.
- 개발용 패널을 식별 가능한 영역으로 묶어 한국어 유지 범위를 명시했다.
- 한국어·영어 각각 시작 설정 3단계, 탑승 확인, 탐험, 일시 정지, 주차 휴식, 놀이터 목록, 퍼즐 설명, 퍼즐 진행, 본편 결과를 628dp/1200dp로 검사했다(44개 조합).
- 텍스트 검사에서는 실제 줄의 글자 폭과 높이·최대 줄 수를 비교하며 물리 픽셀 반올림 1px을 허용한다. 가운데 정렬 문단 전체의 폭을 글자 폭으로 오인하지 않는다.
- 영어 본편에서는 언어 선택지의 자국어 표기 `한국어`와 한국어 유지 영역을 제외하고 한글 누락이 없는지 함께 검사했다.
- 단위 테스트: core 191개, app 44개, 총 235개 통과. Debug 앱·테스트 APK 빌드와 저장소 검사 통과.

기기 시험 중 호스트 GPU의 캡처 처리에서 에뮬레이터가 충돌해 `-gpu swiftshader -no-snapshot-load -no-snapshot-save`로 재실행했다. AVD 설정 파일은 바꾸지 않았다. 반복 캡처는 화면 검사에서 제거했다. 실제 내비 앱 동시 배치·실발화 검증은 이 가상 창 크기 검사에 포함하지 않는다.

후속 기기 결과: 44개 화면 조합 검사 통과. 기존 기기 회귀 16개 중 15개가 통과했고 1개는 `Activity has been destroyed already`로 준비 단계에서 실패했다. 해당 클래스 단독 재시험에서는 그 시험은 통과하고 다른 시험의 시작에서 같은 오류가 나타났다. 따라서 모든 기기 회귀가 안정적으로 통과했다고 표시하지 않는다. 영어 TTS/BGM, Android 포커스, 네 도시 설명 화면, 설정·접근성·주차 결과 화면 시험은 통과했다. 실제 내비·실발화 시험과 위 Activity 시작 불안정성은 별도로 남긴다.
