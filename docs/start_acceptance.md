## 이번 보완

- 카드와 시작 화면 글자에 줄 높이를 지정했다.
- 카드 텍스트가 폭을 충분히 쓰도록 해 글자 측정 시 끝이 잘릴 수 있는 문제를 보완했다.
- 동의 안내의 텍스트 영역 폭을 제한해 좁은 창에서도 줄바꿈되게 했다.
- 시작 설정 사건 목록을 StartSelection으로 분리해 누락 없이 시작 전에 보내도록 했다.

## 범위의 한계

- 크기 시험은 앱 컨테이너의 크기를 바꾼 것이다. 실제 Pleos 분할 창 드래그·모든 기종·모든 글자 배율까지 검증한 것은 아니다.
- 목적지는 현재 파일의 시험 목적지다. 실사용 콘텐츠와 사실 확인은 별도 작업이다.
- 엔진으로 선택을 보내는 것과 연령·목적지별 이야기를 재생하는 것은 다르다. 후자의 엔진 분기는 아직 미구현이다.
- TTS·STT 실제 동작은 후속 음성 이슈다. 이 시험에서 아이 목소리는 쓰지 않았다.
