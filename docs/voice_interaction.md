# 앞쪽 디스플레이의 음성 참여

팀 결정: 액션 퍼즐은 주차·휴식 중에만 조작하고, 주행 중에는 음성·효과음 중심으로 진행한다. 엔진으로 가짜 위치·차량 사건을 보내는 시연 통합 전까지 장소 카드 방식은 유지한다.

## 구현

- 16곳 각각에 교육 원고 기반의 세 보기 음성 퀴즈를 추가했다. 정차 중에는 ‘소리로 퀴즈 풀기’를 선택할 수 있다.
- 보너스는 별도 미니게임 놀이터 화면에서 P일 때만 연다. 기어가 P가 아니거나 주행 규제가 오면 닫고 내부 퍼즐 멈춤을 해제한다. 규제가 오지 않는 재생 모드 D도 같다. 부모가 직접 끈 경우에는 그 끄기를 유지한다. 자동으로 퍼즐 화면으로 돌아오지 않는다.
- 규제 화면은 엔진 상태·멈춤 이유 한 줄과 큰 소리 끄기 버튼만 표시한다. 지도, 퍼즐, 보상 모션, 상세 설명과 번호 터치 입력은 표시하지 않는다. 플랫폼 자체의 앱 차단 정책은 우회하지 않는다.
- TTS의 정상 완료 뒤 450ms 간격을 두고 STT를 요청한다. 말하는 동안에는 마이크를 열지 않는다. 취소하면 예약된 듣기도 무효화한다.
- `Locale.KOREA`, `ON_DEVICE`로 요청하며 출발 전 음성 동의가 켜진 경우에만 듣는다. 동의 철회·소리 끄기·창 닫기·앱이 배경으로 이동하면 듣기를 중단한다.
- ‘1번’, ‘일 번’, ‘2번이요’, ‘세 번째’처럼 명확한 번호만 적용한다. 여러 번호나 문장 속 숫자는 추측하지 않는다. 중간 인식은 채점하지 않고 최종 결과만 사용한다.
- 잘못된 번호 답은 안내 후 다시 듣는다. 무응답·준비 실패는 자동 정답 처리하지 않으며, 정차 중 다시 대답하거나 건너뛸 수 있다. 잘못된 답의 자동 재시도는 두 번으로 제한하고, 무응답 뒤에는 자동으로 계속 듣지 않는다.
- UI는 말하는 중·마이크 준비·듣는 중·답 확인·오류를 구분한다. 원문 발화와 음성 파일은 저장하거나 로그에 남기지 않는다. 선택된 번호만 메모리에 둔다.

## 건너뛰기와 여행 마무리

- ‘이번 미션 건너뛰기’ 또는 음성 퀴즈에서 ‘건너뛰기’로 넘긴다.
- 건너뛴 장소는 ‘다음 기회에’로 표시하고 보물 조각을 지급하지 않는다.
- 네 장소를 성공 또는 건너뛰기로 처리하면 여행 마무리를 열 수 있다. 인사와 보상 그림은 실제 모은 조각 수를 사용한다.
- 건너뛴 장소에 다시 도전해 성공하면 건너뛰기 표시를 제거한다.

## 실제 입력과 시연

- 보너스의 SDK 인식 결과는 해당 퍼즐 상태에 연결한다. 본편은 실제 에피소드의 보기와 번호를 대조해 AnswerHeard로 전달한다. 두 흐름의 보상은 별도다.
- 엔진의 Listen도 실제 STT를 사용하며, 해당 결과는 AnswerHeard로 전달한다. 화면 퀴즈 결과를 엔진의 LineFinished나 AnswerHeard로 위장하지 않는다.
- 왼쪽 차량 3D UI를 읽거나 제어하지 않는다. 차량 SDK 사건을 앱이 받아 쓰는 구조다. 차량 상태별 배경·소리 규칙과 새 효과음은 팀 목록이 정해진 뒤 연결한다.
- 기존 효과음은 임시 합성음이다. AudioFocusSource가 포커스 상실·복귀를 엔진에 전달한다. 일시적 duck 요청에도 TTS·효과음·듣기를 멈춘다. 실제 내비 통합 확인과 최종 음원은 남아 있다.

## 검증 범위

- 번호 문자열 해석, 16개 장소의 세 보기와 완료 판정, 건너뛰기의 보상 분리 시험을 추가했다.
- 인식 대역으로 동의 없을 때 요청 금지, 취소, 늦은 콜백, 중복 결과, 동의 철회를 검증한다.
- Pleos 실제 SDK의 초기화·요청·onReady 인식 준비 통지 및 취소를 확인했다. onStartedRecognition 발화 시작과 최종 발화 인식은 무발화 시험만으로 성공이라고 보지 않는다.
- 초기 시험은 발화 시작 통지를 준비 기준으로 잡아 실패했다. SDK의 onReady 준비 통지와 발화 시작을 구분하고, 사용자가 말할 차례를 준비 시점에 표시하도록 보완했다.
- 실제 성인이 ‘1번’을 말했을 때의 최종 인식 정확도와 차량 소음 환경은 아직 확인하지 않았다.

## 사람이 해볼 순서

정차 상태에서 말로 대답하기 동의 켜기 → 탐험 시작 → 장소 선택 → 소리로 퀴즈 풀기 → 보기를 다 읽고 ‘이제 내 차례’가 나오면 성인이 ‘1번’이라고 말하기. 선택된 번호, 재시도, 건너뛰기와 소리 끄기를 확인한다. 에뮬레이터는 마이크 입력과 호스트의 마이크 권한이 필요하다.

참고: https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/SpeechToText/result-listeners

새 음성 수명·서비스 준비·퀴즈 UI·창 크기 시험 4개 통과. 기존 TTS/효과음 기기 시험 6개도 통과했다. 연속 실행에서 기존 시작 화면 시험의 TTS 초기화 대기가 한 번 실패해 단독 재실행했고, 네 장소 완료까지 통과했다. 실제 발화 정확도 확인은 여전히 남아 있다.
