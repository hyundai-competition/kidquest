# main 통합 (2026-11-09)

기준 main: 25f18c8 (#53까지 머지). 기존 작업은 e317753과 codex/pre-main-integration-20261109 브랜치에 보존했다. 통합 브랜치는 codex/main-integration-20261109이며 원격에 푸시하지 않았다.

## 연결한 것

- core 계약·엔진·예시 대본은 main을 그대로 사용한다. 열린 #54 제안은 포함하지 않는다.
- 목적지 ID는 gyeongju / busan / andong / seoul이고, routeId는 에피소드 routes에서 고른다. 부산은 두 경로 중 선택한다.
- 지도는 고른 경로의 장소 세 곳을 그리고, 공통 임무 두 개를 포함한 보물 다섯 개를 엔진의 AwardItem으로 센다.
- 지도 클릭은 PlaceEntered를 보낸다. 위치 수집기와 재생 패널도 같은 사건을 보낸다. 카드 클릭이 위치 수집 검증을 뜻하지는 않는다.
- TTS·효과음·STT는 기존 실제 음성 구현을 유지한다. 새 효과음 ID는 임시 합성 파일에 연결했으며 정식 음원으로 표시하지 않는다.
- 질문의 기존 lineId를 에피소드 ID와 대조하는 읽기 전용 표시 어댑터를 쓴다. 화면에서 엔진 상태를 변경하지 않는다. 별도 ShowMission 계약은 만들지 않았다.
- 본편 대본은 두 보기 질문이다. EngineChoices는 보기 단어와 질문 속 순서를 대조하고, ‘1번’을 보기 단어로 바꿔 AnswerHeard로 전달한다. 정답 판단과 보상은 엔진이 한다. 확인할 수 없는 질문은 번호 변환 없이 원문 답변을 보낸다.
- 위치 권한을 먼저 결정한 뒤 차량 수집기를 한 번 시작한다. 거절 시 나머지 차량 값과 재생 모드는 유지하고 LOCATION 미지원으로 진행한다.
- 실제 위치 권한을 거절한 뒤 설정 앱에서 허용한 경우에는 앱을 다시 시작한다. 실행 중 자동 권한 복구는 아직 제공하지 않는다.
- 실내 온도 SetBackground는 정박·도착 화면 색에 반영한다. 주행 중 움직이는 그림이나 게임 조작을 추가하지 않았다.
- 도착 화면은 실제 받은 보물과 에피소드 credits를 표시한다.

## 정차 퍼즐

기존 네 도시의 16개 퍼즐은 ‘주차·휴식 중 지역 퍼즐’로 보존했다. 이동 임무와 별도 보상이다. 퍼즐을 열면 이동 엔진을 잠깐 멈추고, D 규제로 들어가면 퍼즐 상태를 보존한 채 이동 엔진을 이어간다. 주행 규제가 풀리면 저장된 퍼즐 화면으로 돌아온다.

## 경주 시연

1. 서울→경주, 경부고속도로를 고르고 연령·말 듣기 동의를 설정한다.
2. 탐험 시작 → 재생 모드에서 탑승·벨트·D를 넣는다. 실제 SDK가 읽는 다른 탑승석도 벨트를 매거나 부모 확인을 사용한다.
3. rain_map 브리핑이 끝나면 와이퍼 켜기, 질문 뒤 ‘답: 파란색’을 보낸다.
4. crossroads 브리핑이 끝나면 ‘갈림길 통과’, 질문 뒤 ‘답: 별’을 보낸다.
5. 천안 근처 → 질문 뒤 답: 8월 15일.
6. 대구 근처 → 질문 뒤 답: 빚.
7. 첨성대 근처 → 질문 뒤 답: 신라.
8. 도착 → P. 결말·전달·사실 문장과 실제 보물 목록, 출처를 확인한다.

재생 모드 D는 엔진 입력만 바꾸고 운영체제 차단을 재현하지 않는다. 실제 콘솔 D의 화면 차단 중 TTS는 signalcheck #35의 결과이며, 통합 제출 앱에서도 별도 확인한다. docs/demo_script.md v3의 깜빡이·열쇠·별 단계는 최신 #52/#39와 달라 이 순서를 사용한다.
