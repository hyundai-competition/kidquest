# 놀이터 퍼즐 16개 문장 출처 확인 (#69)

**AI 초안을 시연·품질이 출처와 대조해 고쳤다.** 2026-11-12 확인. 법률·학술 검수가 아니라 공개 자료를 읽고 맞춰 본 것이다.

- 확인한 파일 : `MissionEducation`(설명), `MissionNotes`(이야기·질문·물건 설명), `CityVoiceQuiz`(세 보기 퀴즈), `CityMissions`(짝 맞추기 답)
- 기준 : 한국민족문화대백과사전(아래 「백과」)을 먼저 보고, 백과에 항목이 없으면 신문 기사를 쓴다.
- 결과 : 16곳 중 **고칠 문장 2곳**(동궁과 월지, 감천문화마을), **백과 대신 신문 출처 3곳**(월영교, BIFF 광장, 국립해양박물관). 나머지는 출처와 맞는다.

## 그 밖에 본 것

- 세 보기 퀴즈의 오답 보기(스마트폰, 운동화 등)는 사실 문장이 아니라 확인하지 않았다.
- `MissionNotes`의 생각할 질문은 답을 정하지 않는 질문이라 사실 확인 대상이 아니다.
- 「영화의 도시」는 부산국제영화제가 열린다는 뜻으로 읽었다. 다른 공식 칭호를 말하려면 따로 확인한다.
- 이 표의 출처를 화면이나 접수 양식에 쓸지는 화면 담당과 정한다. 위 두 문장은 `MissionEducation.kt`에 반영했고, 맨 위 주석의 「외부 출처 검수 전」도 이 문서를 가리키게 바꿨다.
