# 탐험 흐름·미니게임·음성 실패 처리 보완

## 장소 임무가 열리는 기준

- 기본 순서는 공통 임무 rain_map(와이퍼), crossroads(내비 갈림길), 선택 경로의 장소 세 곳이다. 대사 정상 완료 또는 복구 불가 재생 실패의 LineFinished를 받아 다음 단계로 간다.
- 장소 카드는 PlaceEntered를 보내는 시연 입력이다. 현재 대사·질문을 건너뛰는 버튼이 아니다. 먼저 온 장소 사건은 엔진이 기억한다. 뒤 장소를 먼저 선택하면 일부 앞 임무를 보물 없이 건너뛸 수 있는 기존 규칙을 따른다.
- 실제 실행에서는 위치 수집기가 장소 원에 진입했을 때 같은 사건을 보낸다. 위치를 못 읽는다고 선언한 경우에만 장소 임무를 600초 뒤 시간으로 연다. 정상 위치 환경에서는 기다리기만 해서 지역이 바뀌지 않는다.
- 와이퍼 임무는 신호가 없으면 120초 뒤, 갈림길은 안내가 없으면 180초 뒤 대체 진행한다. 내비 안내가 있으면 실제 갈림길 통과를 기다리며 600초 대비책이 있다. 질문 무응답 제한 시간은 별도다.
- 카드를 선택하면 선택한 시연 위치와 현재 대사·앞 임무 뒤 이어진다는 안내를 표시한다. 부모 끄기가 남아 있으면 다시 켜야 본편을 잇는다.

## 대사와 답변

- 본편 대사는 음성 상태 박스 안 한 곳에서만 표시한다. 보너스 설명·질문도 별도 본문이 있으므로 음성 박스에 같은 대사를 복사하지 않는다.
- 질문을 다 읽은 LineFinished 뒤에만 화면 보기를 활성화한다. 읽는 중·멈춤 중 선택과 중복 입력은 받지 않는다.
- 약속 추가: AnswerSelected(word)는 명시적인 화면 선택이다. 마이크 동의 없이도 WAIT_ANSWER에서 채점한다. AnswerHeard는 기존대로 마이크 동의·활성 듣기가 없거나 철회되면 무시한다. 새 사건을 엔진·화면·재생 패널에 연결했다.
- 화면에서 정답을 눌렀는데 동의가 없어 답이 무시되고 무응답 안내로 넘어가던 원인을 수정했다. 정답은 correctLine(맞아요), 오답·무응답은 wrongLine을 쓴다. 후자의 일괄적인 ‘괜찮아요’ 표현을 정답 설명으로 다듬었다.
- 정답 판단과 보상은 계속 엔진에서 한다. 틀렸어도 이야기를 이어가며 보상을 주는 기존 정책은 바꾸지 않았다.

## 미니게임 놀이터

- 본편의 퍼즐 네 개 나열을 없애고 별도 놀이터 화면에 모았다. 부모가 원하는 때 진입한다. 본편 보물과 놀이터 보물은 별도다.
- 현재 기어가 정확히 P이고 주행 규제가 없을 때만 연다. 기어 미확인 상태에서도 열지 않는다.
- 차량 사건을 처리할 때 기어를 확인한다. P 이외 기어 또는 주행 규제가 들어오면 진행 중 퍼즐·놀이터·놀이터 결말을 닫고 내부 ParentStopChanged(true)를 해제한다. 재생 모드에서 DrivingRestricted가 오지 않아도 동작한다.
- 부모가 별도로 소리를 껐다면 그 끄기를 해제하지 않는다. 자동으로 퍼즐 화면을 재개하지 않는다. 완료한 놀이터 보상은 유지하지만 중간 퍼즐은 다시 연다.

## TTS와 녹음이 모두 실패한 경우

- 오류를 기록·표시하고 LineFinished를 한 번 보내 본편이 멈추지 않게 한다. 다음 대사는 계속 재생을 시도한다. 정상 재생 성공 로그와 구분한다.
- 명시적 StopAudio, 포커스 상실, 외부 중단은 여전히 완료 사건을 보내지 않는다. 실패한 과거 재생의 늦은 콜백도 무시한다.
- 보너스 질문 실패 뒤에는 자동 STT를 시작하지 않는다. 본편 진행 사건과 보너스 음성 완료 콜백을 구분한다.

## 검증

- core 179개·앱 JVM 37개, 총 216개 단위 테스트 통과. 앱·테스트 APK 빌드와 저장소 검사 통과.
- Pleos에서 관련 기기 테스트 11개 통과: GameplayFixesTest 2개, TripScreenTest 1개, VoiceQuizUiTest 1개, MissionLayoutTest 1개, IntegratedTripTest 1개, VoicePlaybackTest 5개.
- 화면 답은 마이크 동의 없이도 정답·오답 대사가 구분되고, 읽는 중에는 선택할 수 없는 것을 확인했다. 대사 본문 노드가 하나인 것도 확인했다.
- P에서만 놀이터를 열고, DrivingRestricted 없이 R로 바꾸면 닫히며 본편의 내부 끄기가 해제되는 것을 확인했다. 부모가 끈 상태에서는 D로 바꿔도 부모 끄기가 유지된다.
- 음성 단위 테스트는 녹음 없음·녹음 재생 실패 후 한 번만 진행하고 다음 대사를 읽는 것과 늦은 콜백·명시적 중단의 완료 금지를 검증했다. 실제 녹음 파일은 아직 없다.
- 놀이터와 대사 화면 캡처를 육안 확인했다. 기존 내비 진단 변경은 별도로 보관하며 이번 PR 범위에 포함하지 않는다.
