# 와이퍼 임무 대본 v2

**AI 초안이다. 다 읽고 고친 뒤 이 줄을 "AI 초안을 사람이 읽고 고침"으로 바꿔서 넘긴다.**

## 대사

| 순서 | 대사 |
|---|---|
| 브리핑 | 선장님, 앞에 반짝이는 별가루 구름이 나타났어요. 구름 문을 여는 열쇠는 파란색이래요. |
| 사건 | (별가루 소리) 쓱싹쓱싹! 우주선 빗자루가 별가루를 쓸어 내고 있어요. |
| 질문 | 구름 문 앞에 왔어요. 열쇠는 파란색일까요, 빨간색일까요? |
| 정답 | 맞아요, 파란색! 구름 문이 열리고 별지도 조각을 얻었어요. |
| 오답 | 괜찮아요, 열쇠는 파란색이었어요. 구름 문이 열리고 별지도 조각을 얻었어요. |
| 보상 | 별지도 조각 |

## v1에서 바꾼 점

- 와이퍼 움직임을 "우주선 빗자루"로 바꿔서 차 신호와 이야기를 이었다. 와이퍼 신호 없이 임무가 저절로 열려도 어색하지 않게 "와이퍼"라고 말하지 않는다.
- 질문을 두 가지 중 고르는 말로 바꿔서 어린아이도 답하기 쉽게 했다.
- 오답을 "괜찮아요"로 시작한다. 틀린 답이나 답을 못 한 경우 모두 어울린다.
- 보상을 별가루 병에서 별지도 조각으로 바꿨다. 예시 에피소드의 결말이 "모은 조각으로 별지도를 완성"이기 때문이다.

## 규칙 점검

- 운전자를 부르지 않는다 : 통과. "선장님"은 앱이 아이를 부르는 말이다
- 벨트를 풀게 하지 않는다 : 통과
- 창밖으로 몸을 내밀게 하지 않는다 : 통과
- 혼내지 않는다 : 통과. 틀려도 같은 보상을 준다
- 기존 동화나 캐릭터 : 일부러 가져온 것은 없다. 사람이 읽을 때 한 번 더 본다

## 넘길 때 물어볼 것

1. 예시 파일의 `meteor_shower`도 와이퍼로 열린다. 미취학 아이에게는 와이퍼 임무가 2개가 되니 순서를 정하거나 하나를 빼야 한다.
2. 소리 id `stardust`와 아이템 `star_map_piece`는 새로 제안하는 값이다.
3. 재생 패널에 "답 : 파란색" 버튼이 없다. 시연하려면 추가해야 한다.
