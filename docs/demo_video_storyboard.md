# 시연 영상 콘티 v2

**AI 초안이다. 사람이 읽고 고친다.** 90초는 가정이다. 공식 길이 기준은 찾지 못했다.

## 구성

| 시간 | 장면 | 종류 | 자막 |
|---|---|---|---|
| 0:00~0:08 | 뒷좌석을 그린 그림 | 콘셉트 영상 | [뒷좌석 문제 한 문장. 사실로 확인한 내용만] |
| 0:08~0:15 | 벨트 버클에 재생 표시가 겹치는 그림 | 콘셉트 영상 | 벨트가 재생 버튼인 오디오 모험 |
| 0:15~0:22 | 시작, 탑승 | 실제 앱 | 재생 모드로 차 신호를 넣는 시연입니다 |
| 0:22~0:32 | 벨트 매기, 기어 D, 비행 중 | 실제 앱 | 벨트를 매면 발사 준비가 끝납니다 |
| 0:32~0:52 | 와이퍼 켜기, 별가루 임무, 답 넣기 | 실제 앱 또는 콘셉트 영상 (아래 표) | 실제 차 신호가 우주 사건이 됩니다 |
| 0:52~1:05 | 벨트 풀기, 멈춤, 다시 매기, 복귀 | 실제 앱 | 풀면 멈추고, 다시 매면 이어집니다 |
| 1:05~1:17 | 도착, 기어 P, 착륙 화면 | 실제 앱 | 도착하면 이야기도 끝납니다 |
| 1:17~1:30 | 앱 이름과 원칙 3개 | 자막 화면 | 운전자를 부르지 않습니다 / 혼내지 않습니다 / 벨트를 풀게 하지 않습니다 |

## 녹화 때 임무가 안 돌면

| 11-13 녹화 때 상태 | 0:32~0:52 장면 | 자막 |
|---|---|---|
| 임무와 음성이 돈다 | 실제 앱 | 실제 차 신호가 우주 사건이 됩니다 |
| 임무만 돌고 음성이 없다 | 실제 앱 + 대사 자막 | 음성 구현 예정 |
| 임무가 안 돈다 | 와이퍼가 별가루를 쓸어 내는 그림 | 콘셉트 영상 : 구현 예정 |

## 찍는 법

- 앱 화면은 합성하지 않고 그대로 찍는다. 자막과 음악만 편집으로 넣는다.
- 소리는 앱에서 나는 소리를 그대로 쓴다. 넣은 효과음의 라이선스는 `docs/sound_licenses.md`로 확인한다.
- 재생 패널이 보이게 찍고, 버튼을 누를 때 잠깐 멈춘다.
- 콘셉트 영상은 직접 그린 그림으로 만든다. AI 영상에 돈이나 크레딧이 들면 먼저 팀에 말한다.
- 그림에서는 아이 얼굴을 그리지 않는다. 실제 아이 사진과 목소리는 쓰지 않는다.

## 올리기 전 확인

- [ ] 아이 얼굴과 목소리가 없다
- [ ] 현대차 로고, 번호판, 계정 이름, 실명이 없다. 파일 속성도 본다
- [ ] 실제 앱 장면에 합성이 없다
- [ ] 상상 장면마다 "콘셉트 영상" 표시가 있다
- [ ] 접수양식의 구현됨, 계획 표시와 영상 내용이 같다
- [ ] 로그아웃 상태에서 링크를 열어 본다
