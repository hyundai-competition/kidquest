# 브루미 자동차 캐릭터

내장 image_gen 도구로 승인된 자동차 캐릭터 콘셉트를 투명 배경 PNG로 제작했다. 다른 사이트의 참고 이미지는 앱에 넣지 않았다.

## 파일

`app/src/main/res/drawable-nodpi/`에 배포용 원화를 보관한다.

- `vroomie_idle.png`: 기본 모습
- `vroomie_rain.png`: 노란 우산을 쓴 모습
- `vroomie_turn.png`: 화면 왼쪽을 바라보고 같은 쪽 방향등을 켠 모습
- `vroomie_rain_turn.png`: 우산과 왼쪽 보기를 함께 적용한 모습

오른쪽 보기는 원화를 좌우 반전한다. 실제 차량 방향등을 대신하는 표시가 아닌 앱의 장식 반응이다. 기존 차량 신호와 3.5초 표시 규칙을 그대로 사용하며 임무·보상을 추가하지 않는다. 눈 연출을 선택해도 와이퍼가 켜져 있으면 우산을 쓴다.

## 화면 연결

- 넓은 출발 설정·승무원 확인 화면: 왼쪽 소개 영역에 크게 표시
- 좁은 창·탐험·퍼즐·주행 규제 화면: 뒤로/끝내기 사이에 작게 표시
- 이미지의 투명 여백과 우산 공간을 유지하고 Fit으로 그려 찌그러뜨리지 않는다.
- 정적 이미지 교체만 사용한다. 주행 중 흔들림·이동·점멸 애니메이션은 없다.
- 기존 배경 가장자리 금빛 화살표는 제거했고 비·눈 배경은 유지한다.

## 생성 프롬프트

공통 지시: 승인된 크림색 보송한 자동차, 연두색 지붕, 작은 검은 눈, 볼터치, 귀 같은 사이드미러의 정체성을 유지한다. 캐릭터 한 대만 투명 배경에 그린다. 부드러운 3D 질감, 같은 크기와 바퀴 기준선, 우산을 위한 위쪽 여백을 유지한다. 글자·패널·바닥·배경 장면은 넣지 않는다.

포즈별 지시:

- 기본: 정면을 바라보며 웃기. 우산과 켜진 방향등 없음.
- 비: 같은 캐릭터에 작은 겨자색 우산을 지붕 위에 펼치기. 눈은 뜨고 정면 보기.
- 방향: 화면 왼쪽을 곁눈질하고 왼쪽 작은 주황색 방향등 켜기. 몸을 흔들지 않기.
- 비와 방향: 방향 포즈에 같은 노란 우산을 유지하기.

방향 포즈의 최종 편집은 캐릭터·시선·크기·투명 여백을 유지하면서 켜진 램프만 화면 왼쪽으로 옮기도록 지시했다.

## 확인
