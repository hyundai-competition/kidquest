# 시연 대본 v3 : 브루미

**AI 초안이다. 발표자가 읽고 자기 말로 고친다.** 약 3분은 가정이다. 공식 시간을 확인하면 맞춘다.

- 팀 : 로디버스(Roadiverse) / 앱 : 브루미(Broomy)
- 한 문장 메시지 : **벨트가 재생 버튼입니다. 차가 움직이면 가는 지역의 역사 보물찾기가 소리로 펼쳐집니다.**
- 시연 경로 : 서울 → 경주 (예시 파일 `episode_demo.json` 기준)
- 준비 : 에뮬레이터에서 앱을 켜고 재생 패널을 펼친다. 음성과 효과음 볼륨을 맞춘다.
- 「지금」 칸 : PR #37(목적지와 장소 임무)과 재생 패널 장소 버튼이 main에 들어간 뒤 기준이다. 음성은 아직 가짜라 대사는 로그(`KidQuestVoice`)에 찍힌다.
- 재생 패널의 D 버튼은 엔진에만 신호를 넣어서 화면이 가려지지 않는다. 실제 차(콘솔 기어 D)에서는 「주행 중에는 사용할 수 없습니다」로 화면이 가려지고 소리만 이어진다(PR #35 시험). 시연에서 이 점을 먼저 밝힌다.

## 시작 (25초)

> [뒷좌석 문제 한 문장. 사실로 확인한 내용만 넣는다.]
>
> 저희 앱 브루미는 뒷좌석 아이를 위한 오디오 보물찾기입니다. 벨트를 매야 시작되고, 풀면 멈춥니다.
>
> 달리는 동안 차는 앱 화면을 가립니다. 그래서 브루미는 처음부터 소리로만 진행하고, 와이퍼와 깜빡이 같은 실제 차 신호와 가는 곳의 장소가 이야기 속 사건이 됩니다.
>
> 오늘은 재생 모드로 차 신호를 넣어 서울에서 경주 가는 길을 보여 드리겠습니다.

## 시연 (2분 10초)

| 순서 | 누르는 것 | 앱이 하는 말 | 발표자 말 | 지금 |
|---|---|---|---|---|
| 1 | 재생 패널 「목적지 : 경주」, 「듣기 동의」 → 화면 「시작」 | (탐험대원 확인 화면) | 부모가 출발 전에 목적지와 듣기 동의를 고릅니다. 실제로는 시작 화면에서 고릅니다. | 됨 (재생 패널). 시작 화면은 PR 전 |
| 2 | 탑승 | 「탐험대원을 확인했어요. 벨트를 매면 출발 준비가 끝나요.」 | 아이가 타면 앱이 먼저 벨트를 안내합니다. | 됨 |
| 3 | 벨트 매기 | 「대장님, 출발 준비 끝났어요.」 | 벨트가 곧 재생 버튼입니다. | 됨 |
| 4 | D | 「출발! 보물 탐험을 시작해요.」 → 「오늘은 서울에서 경주까지 가요. 신라 사람들이 남긴 보물을 찾으러 출발해요!」 → 「대장님, 보물 지도에 물방울이 묻으면 글씨가 흐려진대요. 지도 속 열쇠는 파란색이래요.」 | 차가 출발하면 이야기도 출발합니다. 여기서부터 실제 차는 화면을 가리고 소리만 나옵니다. | 됨 |
| 5 | 와이퍼 켜기 | (효과음) 3~4초 뒤 「쓱싹쓱싹! 지도에 묻은 물방울을 닦았더니 글씨가 다시 보여요.」 → 「보물 상자 열쇠는 파란색일까요, 빨간색일까요?」 | 운전자가 켠 와이퍼를 앱이 읽어서 사건으로 만듭니다. 앱이 와이퍼를 켜지는 않습니다. | 됨 |
| 6 | 답 : 파란색 | 「맞아요, 파란색! 열쇠로 보물 지도 조각을 꺼냈어요.」 → 다음 브리핑 「대장님, 가는 길에 갈림길이 있대요…」 | 아이는 말로 답합니다. 시연에서는 목소리 대신 버튼으로 넣습니다. 틀려도 혼내지 않고 같은 보물을 줍니다. | 됨 (듣기 동의가 있어야) |
| 7 | 벨트 풀기 → 벨트 매기 | 풀면 「벨트를 매면 계속할 수 있어요.」 매면 이어짐 | 벨트를 풀면 이야기가 멈추고, 다시 매야 이어집니다. | 됨. 신호를 기다리는 중이면 다시 맬 때 말이 없다 |
| 8 | 오른쪽 깜빡이 | 「깜빡깜빡! 갈림길에서 보물 표시를 찾았어요.」 → 「보물 상자를 여는 건 열쇠일까요, 숟가락일까요?」 | 깜빡이도 사건이 됩니다. 신호를 못 읽는 차는 정해진 시간이 지나면 저절로 열립니다. | 됨 |
| 9 | 답 : 열쇠 | 「맞아요, 열쇠예요! 갈림길 보물 조각을 찾았어요.」 → 「대장님, 경주 보물은 별을 보던 돌 건물 근처에 숨어 있대요. 가까워지면 알려 줄게요.」 | | 됨 |
| 10 | 첨성대 근처 | 「경주에 들어왔어요! 옛날 신라 사람들이 별을 보던 첨성대가 이 근처에 있어요.」 → 「첨성대는 별을 보던 곳일까요, 물고기를 잡던 곳일까요?」 | 실제 위치가 첨성대 근처에 들어오면 열립니다. 시연에서는 버튼으로 넣습니다. | 엔진 됨. 진짜 위치 연결은 차량·내비 몫 |
| 11 | 답 : 별 | 「맞아요, 별을 보던 곳이에요! 첨성대 보물 조각을 찾았어요.」 | 보물 세 개를 다 찾았습니다. | 됨 |
| 12 | 도착 → P | 결말 「오늘 찾은 보물 조각을 하나로 맞췄어요. 정말 멋진 탐험이었어요, 대장님!」 → 「경주에 도착했어요! … 경주 보물 상자를 열었어요.」 → 사실 「첨성대는 별을 관측하려고 높이 쌓은 대예요…」 → 「도착! 오늘의 배지를 확인해 보세요.」 | 도착하면 이야기를 맺고, 확인한 사실 한 문장을 들려줍니다. 차가 서 있을 때만 보물 화면을 보여 줍니다. | 됨 (보물 화면은 화면 담당) |

- **제안 (팀 확인 전)** : 9번과 10번 사이에 「5분 남음」을 누르면 「경주가 거의 다 왔어요. 마지막 보물이 기다리고 있어요.」가 나온다(PR #38). 보물을 다 찾기 전에만 나오니 이 자리에만 넣을 수 있다. 「곧 도착」 느낌이 살지만 약 5초 길어진다.
- 시간이 모자라면 7번을 뺀다. 8~9번은 빼면 안 된다. 임무는 순서대로라 깜빡이 임무를 끝내야 장소 임무로 간다(신호가 없으면 3분 기다림).
- 답 버튼은 「듣기 동의」를 누른 뒤에만 쓰인다. 안 누르면 8초 뒤 정답을 알려 주고 넘어간다.

## 마무리 (25초)

> 정리하면, 벨트로 시작하고, 실제 차 신호와 장소로 보물을 찾고, 도착하면 끝납니다.
>
> 운전자를 부르지 않고, 내비가 말하면 비켜 주며, 아이 목소리는 저장하지 않습니다.
>
> 지금은 경주, 부산, 안동, 서울 네 경로가 있고, 대사는 파일로 분리되어 있어 지역을 계속 늘릴 수 있습니다.

## 문제가 생기면

| 상황 | 할 일 | 말 |
|---|---|---|
| 앱이 멈춤 | 앱을 다시 켜고 1번부터 | 다시 시작하겠습니다. |
| 다시 켜도 안 됨 | 녹화 영상 재생 | 같은 흐름을 녹화 영상으로 보여 드리겠습니다. |
| 소리가 안 남 | 로그를 보며 대사를 읽는다 | 소리가 나오지 않아 제가 읽겠습니다. |
| 목적지를 시작 뒤에 눌렀다 | 착륙 뒤 「다시 하기」 → 목적지 먼저 | 순서를 바로잡겠습니다. |
