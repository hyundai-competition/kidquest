# 주행 화면·음성 양보·본편 결과 (이슈 #26~#28)

## 구현

- 주행 규제 중에는 엔진의 상태·멈춤 이유 한 줄과 큰 소리 끄기/다시 켜기만 표시한다. 상세 설명·음성 상태 패널·퍼즐·지도·보상 모션은 구성하지 않는다.
- 정박 화면에서도 부모가 카시트·벨트를 직접 확인할 수 있다. 확인 사건은 ParentConfirmedBelt이며 센서 값을 변경하지 않는다.
- 보너스의 소리 끄기는 문제 다시 읽기·다른 퍼즐 열기·주행 전환으로 풀리지 않는다. 악기 미리 듣기와 성공 안내도 끄기를 따른다.
- AudioFocusSource는 USAGE_MEDIA, CONTENT_TYPE_SPEECH로 소리 사용권을 요청한다. duck 요청에도 음량만 줄이지 않고 멈추도록 설정한다.
- 포커스를 잃으면 TTS·효과음·악기·STT·예약된 듣기를 취소하고 AudioFocusChanged(false)를 보낸다. 복귀 때 true를 보내고 본편 재개 판단은 엔진에 맡긴다. 부모 끄기·벨트 중단 이유가 남으면 임무를 재개하지 않는다.
- 일시적 포커스 상실·지연 획득 중에는 새 음성과 다시 켜기 조작으로 사용권을 빼앗지 않는다. 영구 상실·요청 거절 뒤에는 부모의 다시 켜기로 재요청한다. 연결 종료 때 사용권을 반납한다.
- 보너스 퍼즐은 포커스가 돌아와도 자동으로 읽거나 듣지 않는다. 정차 중 다시 읽기 또는 소리 끄기/다시 켜기로 참여한다.
- Listen 전에 동의와 pleos.car.permission.STT_SERVICE 권한을 확인한다. 실제 녹음은 Pleos 서비스가 수행하며, 호스트 마이크 입력 가능 여부는 SDK 준비·오류·시간 초과로 처리한다.
- 도착 대사는 진행 위치를 기억한다. 포커스 상실·부모 끄기로 중단되면 허용된 뒤 현재 문장을 처음부터 읽고, 완료한 결말은 다시 시작하지 않는다.
- 본편 도착 화면에 실제 AwardItem 개수와 계획 임무 수로 채운 정적인 보물 지도를 표시한다. 보너스 4조각과 섞지 않는다. 보물 0개면 다음 탐험을 권하는 문구를 표시한다.
- 배경은 기존 NORMAL/COOL/WARM을 사용하고 기본값은 NORMAL이다. 다시 하기는 엔진 RestartPressed로 본편 결과를 정리하고, 보너스·동의·설정 단계도 초기화한다.

## 확인 범위와 제한

- core 174개·앱 JVM 35개 테스트 통과, 디버그 APK·AndroidTest APK 빌드 성공, 저장소 규칙 검사 통과.
- Pleos API 34에서 관련 기기 테스트 12개 통과: AudioFocusTest 2개, TripScreenTest 1개, IntegratedTripTest 1개, VoiceEngineConnectionTest 1개, VoicePlaybackTest 5개, RecognitionLifecycleTest 1개, VoiceQuizUiTest 1개.
- 실제 Android의 내비 용도 경쟁 포커스 요청으로 상실·복귀를 확인했다. 일시적 상실 중 재요청하지 않는 것도 확인했다. 실제 내비 앱 안내를 시험한 결과는 아니다.
- 인식 대역으로 포커스 상실 때 취소·늦은 답 무시를 확인했다. 실제 STT 서비스의 초기화·요청·onReady 준비 통지도 확인했지만 발화 정확도 검증은 아니다.
- 360dp·628dp 창의 결과 그림·보상·다시 하기와 화면 크기 변경 후 끄기 유지를 확인했다. 보물 0개·일부 수집, 보너스 끄기 후 주행 전환과 닫기도 확인했다.
- 실제 ON_DEVICE TTS 완료가 본편 브리핑으로 연결되고, 기존 재생 중단·녹음 대체 경로 시험도 통과했다. 녹음 대체는 테스트 합성음이며 실제 대사 녹음이 아니다.

보너스 음성은 부모가 다시 참여할 때 시작하며, 포커스 복귀만으로 자동 재생하지 않는다. 연속 화면 전환 때 처리 대기 중인 부모 끄기 요청을 내부 퍼즐 멈춤과 혼동하지 않도록 최신 요청을 따로 보관한다.

현재 로컬 Pleos의 마이크 입력은 호스트 오디오 교착을 피하기 위해 꺼져 있다. 인식 대역의 취소 시험은 가능하지만 실제 발화 정확도를 검증한 것으로 보지 않는다. 실제 내비와의 포커스 정책, 내비 안내 직전 선제 중단, 최종 녹음·음원은 남아 있다.

참고: Android 공식 [오디오 포커스](https://developer.android.com/media/optimize/audio-focus), AOSP [차량 오디오 포커스](https://source.android.com/docs/automotive/audio/audio-focus).
