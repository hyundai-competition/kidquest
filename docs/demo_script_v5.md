# 시연 대본 v5 : 브루미 (Vroomie)

**AI 초안이다. 발표자가 읽고 자기 말로 고친다.**

- 팀 : 로디버스 / 앱 : 브루미 (Vroomie). 앱 이름은 접수 양식에 맞췄다.
- 한 문장 메시지(접수 양식 1번과 같은 뜻) : **뒷좌석 아이가 벨트를 매야 시작되고, 차가 지나는 길을 따라 그 지역의 역사 보물을 목소리로 찾아가는 탐험입니다.**
- 시연 경로 : 서울 → 경주, 경부고속도로 (천안 → 대구 → 첨성대)
- 기준 : #80(자동 시연 모드)과 정답 순서 바꾸기(갈림길·첨성대 정답이 2번)가 main에 들어간 상태. v4의 재생 패널 버튼은 일반 화면에서 사라졌다.
- 걸리는 시간 : 답을 안 눌러도 약 3분 48초에 끝까지 간다(`showcase_mode.md`, 11/11 기록). 답을 바로 누르고 「다음 구간」을 쓰면 줄어든다. 줄어든 시간은 녹화하며 잰다.

## 준비

- 에뮬레이터 콘솔 기어를 **P**에 둔다. 차 기기에서는 실제 P가 아니면 시연이 시작되지 않는다.
- 마이크는 에뮬레이터에서 꺼 두었으니 「말로 대답하기」는 끈다. 답은 화면 위쪽 시연 영역의 보기로 누른다.
- 음성 볼륨을 맞춘다. 화면 위에 「시연 모드 · 가상 차량·위치 신호로 진행합니다」가 계속 보이는지 본다.

## 시작 (20초)

> 가족이 차로 오래 가면 뒷좌석 아이는 금방 지루해하고, 운전하는 부모는 뒤를 돌아보거나 휴대폰을 건넵니다.
>
> 브루미는 차가 이미 아는 신호, 벨트·기어·와이퍼·내비 갈림길·지나는 도시로 움직이는 오디오 보물찾기입니다.
>
> 오늘은 시연 체험 모드로 서울에서 경주 가는 길을 보여 드리겠습니다. 이 모드는 가상 차량·위치 신호를 넣는다고 화면에 계속 표시합니다.

## 시연

| 순서 | 누르는 것 | 앱이 하는 말 | 발표자 말 |
|---|---|---|---|
| 1 | 첫 화면 「시연 체험」 → 「한국어」 → 「경로 고르기」 → 서울 → 경주, 「경부고속도로」 → 테마 → 「시연 시작」 | (시연 화면으로 바뀜) | 부모가 차가 서 있을 때 언어와 경로를 고릅니다. |
| 2 | 없음 (자동 : 가상 탑승·벨트) | 「탐험대원을 확인했어요. 벨트를 매면 출발 준비가 끝나요.」 → 「대장님, 출발 준비 끝났어요.」 | 뒷좌석에 아이가 타고 벨트를 매야 시작됩니다. 벨트가 재생 버튼입니다. |
| 3 | 없음 (자동 : 가상 D) | 「출발! 보물 탐험을 시작해요.」 → 「오늘은 서울에서 경주까지 가요. …」 → 와이퍼 브리핑 | 차가 출발하면 이야기도 출발합니다. 실제 차는 달리는 동안 화면을 가리고, 브루미는 소리로 이어 갑니다. |
| 4 | 없음 (자동 : 와이퍼) | (쓱싹 소리) 「쓱싹쓱싹! 와이퍼처럼 지도에 묻은 물방울을 닦았더니 …」 → 「보물 상자 열쇠는 파란색일까요, 빨간색일까요?」 | 운전자가 켠 와이퍼를 앱이 읽어서 사건으로 만듭니다. 앱이 와이퍼를 켜지는 않습니다. |
| 5 | 보기 **1번 · 파란색** | 「맞아요, 파란색! …」 → 갈림길 브리핑 「갈림길 보물 표시는 별 모양이래요.」 | 실제로는 아이가 말로 답합니다. 오늘은 화면으로 고릅니다. |
| 6 | 없음 (자동 : 내비 회전 통과) | 「반짝! 갈림길 보물 표시가 나타났어요.」 → 「갈림길 보물 표시는 하트 모양일까요, 별 모양일까요?」 | 내비가 알려 준 갈림길을 지나면 사건이 됩니다. |
| 7 | 보기 **2번 · 별** | 「맞아요, 별 모양이에요! …」 → 천안 브리핑 | |
| 8 | 없음 (자동 : 천안 근처) | 「천안 근처에 왔어요! … 독립기념관 …」 → 「독립기념관이 문을 연 날은 8월 15일일까요, 3월 1일일까요?」 | 지나가는 도시마다 그 지역 이야기가 열립니다. |
| 9 | 보기 **1번 · 8월 15일** | 「맞아요, 8월 15일이에요! …」 → 대구 브리핑 | |
| 10 | 없음 (자동 : 대구 근처) → 보기 **1번 · 나라 빚을 갚기** | 국채보상운동 이야기 → 질문 → 「맞아요, 나라 빚을 갚자는 운동이에요! …」 | (빠르게 넘긴다) |
| 11 | 없음 (자동 : 첨성대 근처) → 보기 **2번 · 신라** | 「경주에 들어왔어요! …」 → 「첨성대에서 별을 보던 사람들은 조선 사람들일까요, 신라 사람들일까요?」 → 「맞아요, 신라 사람들이에요! …」 | 보물 다섯 개를 다 찾았습니다. |
| 12 | 없음 (자동 : 가상 도착 → P) | 결말 → 사실 「첨성대는 …」 → 「탐험 끝! 오늘 모은 보물을 확인해 보세요.」 → 보물 화면 | 도착하면 이야기를 맺고, 출처를 확인한 사실 한 문장을 들려줍니다. |

- **정답 순서** : 1번 → **2번** → 1번 → 1번 → **2번**. v4와 다른 곳은 굵게 적었다.
- 보기는 질문을 다 읽은 뒤에만 눌린다.
- 기다리는 시간이 길면 「다음 구간」을 누른다. 지금 대사는 끊지 않고 다음 신호를 앞당긴다.
- 틀린 답을 보여 주고 싶으면 7번에서 1번(하트)을 누른다. 정답을 알려 주고 같은 보물을 준다.

## 시연 체험 모드에서 보여 줄 수 없는 것

| 빠진 것 | 대신 말로 하거나 따로 찍기 |
|---|---|
| 벨트를 풀면 멈춤 | 「달리는 중에 벨트를 풀면 이야기가 멈추고, 다시 매면 이어집니다.」 |
| 휴게소 놀이터(P에서만 열림) | 시연을 끝낸 뒤 「실제 탐험」에서 P로 놀이터를 열어 따로 찍을지 정한다 |
| 실제 D에서 화면 가림 | 시연 중 실제 기어를 D로 바꾸면 시연이 끝난다. 화면 가림은 #35 시험 영상이나 말로 보여 준다 |

## 마무리 (20초)

> 정리하면, 벨트로 시작하고, 실제 차 신호와 지나가는 도시로 보물을 찾고, 도착하면 끝납니다.
>
> 운전자를 부르지 않고, 내비가 말하면 비켜 주며, 아이 목소리는 저장하지 않습니다.
>
> 지금은 목적지 4곳, 경로 5개가 있고, 이야기는 파일로 나뉘어 있어 지역을 계속 늘릴 수 있습니다.

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 「시연은 실제 차량이 주차(P) 중일 때 …」가 뜸 | 콘솔 기어를 P로 두고 다시 「시연 시작」 |
| 시연이 갑자기 끝남 | 콘솔 기어가 D로 바뀌었는지 본다. P로 두고 1번부터 |
| 소리가 안 남 | 위쪽 시연 영역 대사를 읽는다 |
| 다시 해도 안 됨 | 미리 녹화한 영상을 튼다 |

## 정할 것

1. 공식 발표·영상 시간 확인. 자동 시연만 3분이 넘을 수 있다. 영상이면 기다리는 구간을 잘라도 되는지 정한다.
2. 놀이터 장면을 따로 찍을지.
3. 예상 질문 표는 v4 것을 그대로 쓰되, 「진짜 차 신호인가요?」 답을 「시연 체험 모드는 가상 신호이고 화면에 그렇게 표시합니다. 실제 탐험 모드는 차 신호로만 진행합니다.」로 바꾼다.
