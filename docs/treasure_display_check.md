# 보물 결과 화면 로컬 통합 점검

## 기준과 범위

- 기준 main: `1c5541b` (#73, #71, #72 머지).
- 로컬 브랜치: `feature/treasure-display-fixes`.
- 열린 #75의 영어 보물 이름과 #76의 사진·출처·보물 등장 화면을 커밋 없이 로컬에 적용했다. 원격 PR을 머지하거나 수정하지 않았다.
- 이번 보완: 기어·주행 규제를 반영한 등장 효과 제한, 이름의 가용 폭 확보, 사진의 중복 접근성 읽기 제거, 통합 시험 보완.

## 고친 점

`LANDED` 상태만으로 주차 중이라고 가정하지 않는다. 결과 화면이 남은 채 기어가 D로 바뀔 수 있다.

- `VehicleUiState.decorationsMayAnimate`: 기어 P이고 주행 규제가 없을 때만 true. 기어 미확인·D/R/N·규제 상태는 false다.
- 결과 화면은 이 값으로 `TreasureReveal`의 효과를 제어한다.
- false가 되면 진행 중이거나 지연 중인 효과를 취소하고 즉시 불투명·원래 크기로 표시한다.
- 다시 P로 바꿔도 이미 공개한 보물을 숨기거나 효과를 처음부터 반복하지 않는다.
- 사진은 장식으로 처리해 이름을 두 번 읽지 않는다. 보물 이름 Text가 접근성 텍스트를 제공한다.
- 보물 이름은 사진을 제외한 남은 폭에서 줄바꿈한다. 사진은 96dp 정사각형이다.
- 기존의 출처 개수 2개 고정 검사는 사진 출처가 늘어나는 통합에 맞지 않아, 역사·지도 출처의 보존을 검사하도록 수정했다. 사진 출처 문구는 #76의 내용을 보존했다.

## 검증

- core 192개, app 49개, 총 241개 단위 테스트 통과.
- Debug 앱·테스트 APK 빌드, 저장소 검사·diff 공백 검사 통과.
- 기어 미확인·P/D/R/N 및 규제 여부의 장식 허용 조건 검증.
- 실제 렌더링 이미지 비교로 P→D/R/N 전환 직후 정적 표시와 P 복귀 시 재등장하지 않음을 확인했다.
- 결과 사진 4장·한영 이름·빈 보상·628dp/1200dp 배치 검사 통과. 사진은 실제 렌더링에서 96dp 정사각형이며 이름·다시 하기 버튼을 스크롤로 확인했다.

표시 시험은 에피소드의 실제 보물 ID/이름으로 화면 보상 목록을 채웠다. 실제 위치를 따라 네 목적지 임무를 모두 완료한 시험과는 구분한다.

호스트 GPU 캡처 충돌이 재발해 에뮬레이터를 `-gpu swiftshader -no-snapshot-load -no-snapshot-save`로 재실행했다. AVD 설정 파일은 바꾸지 않았다. Activity가 시작 중 종료되는 기존 환경 불안정성이 있어 단독 재실행 결과를 별도로 기록한다. 두 신규 기기 시험은 각각 단독 성공 기록이 있으나, 캡처 대기 보완 후 추가 재실행에서도 준비 단계의 Activity 종료가 발생했으므로 기기 실행이 항상 안정적이라고 표시하지 않는다.
