# 일반 탐험과 자동 시연

## 첫 화면

기본 선택은 **실제 탐험**이다. 언어 설정 단계에서 **시연 체험**을 선택하고 경로·테마를 고른 뒤 **시연 시작**을 누른다. 마이크 동의는 선택 사항이며 기본은 OFF다. 개발 확인 영역과 수동 재생 패널은 일반 화면에서 제거했다. ReplaySource와 ReplayPanel 소스는 기존 시험 호환을 위해 보관한다.

실제 탐험에서는 실제 차량·위치 사건으로 진행한다. 본편 경유지 카드를 눌러 가짜 위치 사건을 넣는 기능도 일반 화면에서는 제공하지 않는다. 주차용 미니게임은 기존처럼 별도로 사용할 수 있다.

## 시연 진행

- 가상 탑승·벨트 확인 → 준비 안내 → 가상 D 출발
- 대본 브리핑을 실제 TTS로 마친 뒤 와이퍼·내비 회전 통과·현재 경유지 진입을 순서대로 재생
- 질문에는 실제 마이크나 화면 답변을 사용할 수 있고, 무응답은 기존 엔진의 설명·보상 규칙으로 진행
- 모든 임무의 보상을 받은 뒤 가상 도착·P 입력 → 엔진의 결말·전달·사실·마지막 인사

시연기는 LineFinished, AnswerSelected, AnswerHeard, 보상을 만들지 않는다. LineFinished는 기존 음성 계층이 정상 완료 또는 음성 재생 불가 처리 시 보낸다. 경로·언어에 맞는 대본과 실제 엔진을 그대로 쓴다.

화면에는 **시연 모드 · 가상 차량·위치 신호로 진행합니다**를 계속 표시한다.

시연 중 현재 대사·마이크 상태·답변 보기는 상단 시연 영역에서 표시하고 본편 하단에 중복 표시하지 않는다. 질문을 끝까지 읽기 전에는 답변 버튼이 비활성이다.

- **일시정지 / 계속 진행**: 가상 시계·신호와 본편 음성을 함께 멈추거나 재개한다.
- **다음 구간**: 현재 대사를 끊지 않고 다음 신호를 예약한다. 질문 완료 후에는 엔진의 무응답 대기 시간만 줄일 수 있다.
- **시연 종료**: 확인 후 설정 화면으로 돌아가 실제 차량 신호를 복구한다.

실제 내비 경로를 요청하거나 기본 내비 안내 음성을 흉내 내는 기능은 아니다. 대회 규정상 시뮬레이션 허용 여부를 확인했다는 의미도 아니다.

## 입력원과 수명 관리

- 실제 수집기는 시연 중에도 최신 값을 기억하지만 시연 엔진에 차량·위치 사건을 섞지 않는다.
- 자동차 기기는 실제 기어 P가 확인돼야 시연을 시작한다. 일반 안드로이드 기기는 기어 값이 없어도 시연할 수 있다.
- 실제 기어가 P에서 벗어나거나 실제 주행 규제가 들어오면 시연을 종료한다. 가상 P로 실제 주행 제한을 풀지 않는다.
- 종료·뒤로·앱 종료 시 예약 신호를 취소하고 대기 중인 이전 입력원의 사건을 버린다.
- 엔진 재시작이 탑승·벨트를 유지하는 점을 고려해, 입력원 전환 시 모든 자리 값을 실제 스냅샷으로 다시 채운다.
- 가상 답변·위치·보상을 일반 모드나 기기 저장소로 옮기지 않는다.
- ViewModel이 시연 상태를 보관하므로 Activity 재생성 중 새 타이머를 만들지 않는다. 프로세스를 새로 시작하면 기본 일반 모드다.

## 검증

- ShowcaseSignalsTest: 실제 신호 격리·실제 D/주행 규제·알 수 없는 기어·실제 탑승 복구
- ShowcaseRunnerTest: 한국어·영어 대본의 준비된 경로 전체를 실제 엔진과 연결한 완주, 대사 완료 대기·중복 위치 방지·정지 중 시계 유지
- ShowcaseControllerTest: 실제 Android 큐에서 늦은 가상 신호/시작 사건 폐기, 실제 D로 시연 종료
- ShowcaseModeTest: 첫 화면 진입·정지·재개·다음 구간 예약·종료 확인, 선택형 실제 ON_DEVICE TTS 완주

단위 시험의 음성 완료는 시험 대역이다. 실제 TTS 한 판은 아래 명령으로 별도 확인한다. 실제 아이 목소리나 위치를 저장하지 않는다.

```sh
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument --user 10 -w -e verifyShowcase true -e timeout_msec 540000 \
  -e class 'com.kidquest.app.ShowcaseModeTest#automaticTripWithActualOnDeviceNarration' \
  com.kidquest.app.test/androidx.test.runner.AndroidJUnitRunner
```

Pleos 자동차 에뮬레이터는 실제 가상 차량 콘솔을 P로 둔다. 앱의 시연 D와 콘솔의 실제 D는 구분한다. 4개 목적지·5개 준비 경로와 두 언어의 단위 시험 성공을, 실제 내비·실발화·모든 기기의 안정성 검증으로 표현하지 않는다.

## 2026-11-11 확인 결과

- 단위 시험: core 192개 + app 56개 = 248개 통과.
- debug 앱·시험 APK와 release 미서명 APK 빌드 통과. release 빌드는 배포·서명 완료를 뜻하지 않는다.
- 최종 기기 시험 8개 통과: 입력원 전환 1개, 시연 조작 1개, 기존 시작 설정 2개, 주차 퍼즐 2개, 일반 모드 신호 대기 1개, 실제 TTS 한 판 1개.
- 서울→경주 자동 시연은 마이크 OFF·답변 미입력으로 약 227초에 완주했다.
- 대사·답변을 상단으로 모은 최종 화면에서는 중간 대사 정지·재개까지 포함해 약 228초에 다시 완주했다. 보물 5개와 마지막 인사 완료.
- 최종 음성 로그: 정상 완료 27개, 재생 오류 0개, 녹음 대체 0개. 정지했던 첫 브리핑은 2회 시작·1회 완료로, 중단된 재생의 완료 사건을 만들지 않고 처음부터 다시 읽었다.
- 질문의 화면 답변이 활성화되고, 하단에 대사를 중복 표시하지 않는 것도 확인했다.

실제 STT 발화 정확도, 실제 내비의 연속 위치·안내와의 통합, 기존 Pleos 런처/DrivingView의 모든 간헐 충돌 해결을 검증한 결과는 아니다.
