# 시연 대본 v4 : 브루미

> 현재 앱의 진입·조작은 [자동 시연 모드](showcase_mode.md)를 따른다. 아래 수동 재생 패널 조작은 과거 대본이며 일반 화면에서는 제공하지 않는다.

**AI 초안이다. 발표자가 읽고 자기 말로 고친다.** 약 3분은 가정이다. 공식 시간을 확인하면 맞춘다.

- 팀 : 로디버스(Roadiverse) / 앱 : 브루미(Broomy)
- 한 문장 메시지 : **벨트가 재생 버튼입니다. 차가 움직이면 가는 지역의 역사 보물찾기가 소리로 펼쳐집니다.**
- 시연 경로 : 서울 → 경주, 경부고속도로 (천안 → 대구 → 첨성대)
- 기준 : #39(경로와 지나는 도시), #52(내비 갈림길), #55(화면과 음성), #56(쉬운 문장), #57(화면으로 답하기, 미니게임 놀이터)이 main에 들어간 상태. 대사는 `episode_demo.json`과 `Lines.kt`에서 옮겼다.
- 준비 : 에뮬레이터에서 앱을 켜고 재생 모드를 펼친다. 음성과 효과음 볼륨을 맞춘다. 에뮬레이터는 마이크를 꺼 두었으니(`docs/main_integration.md`) 답은 화면 보기나 재생 패널 답 버튼으로 넣는다.
- 재생 패널의 D 버튼은 엔진에만 신호를 넣어서 화면이 가려지지 않는다. 실제 차(콘솔 기어 D)에서는 「주행 중에는 사용할 수 없습니다」로 화면이 가려지고 소리만 이어진다(#35 시험). 시연에서 이 점을 먼저 밝힌다.

## 시작 (25초)

> [뒷좌석 문제 한 문장. 사실로 확인한 내용만 넣는다.]
>
> 저희 앱 브루미는 뒷좌석 아이를 위한 오디오 보물찾기입니다. 벨트를 매야 시작되고, 풀면 멈춥니다.
>
> 달리는 동안 차는 앱 화면을 가립니다. 그래서 브루미는 소리로 진행하고, 와이퍼와 내비 갈림길 같은 실제 차 신호와 지나가는 도시가 이야기 속 사건이 됩니다.
>
> 오늘은 재생 모드로 차 신호를 넣어 서울에서 경주 가는 길을 보여 드리겠습니다.

## 시연 (2분 10초)

| 순서 | 누르는 것 | 앱이 하는 말 | 발표자 말 |
|---|---|---|---|
| 1 | 시작 화면 : 경로 「서울 → 경주」, 「경부고속도로」 → 테마 → 연령, 「말로 대답하기」 → 「탐험 시작하기」 | (탐험대 확인 화면) | 부모가 차가 서 있을 때 경로와 아이 나이를 고릅니다. 말로 대답하기는 부모가 켤 때만 씁니다. |
| 2 | 재생 패널 「탑승」 | 「탐험대원을 확인했어요. 벨트를 매면 출발 준비가 끝나요.」 | 아이가 타면 앱이 먼저 벨트를 안내합니다. |
| 3 | 「벨트 매기」 | 「대장님, 출발 준비 끝났어요.」 | 벨트가 곧 재생 버튼입니다. |
| 4 | D | 「출발! 보물 탐험을 시작해요.」 → 「오늘은 서울에서 경주까지 가요. 천안과 대구를 지나 신라 사람들이 남긴 보물을 찾으러 출발해요!」 → 「대장님, 보물 지도에 물방울이 묻으면 글씨가 흐려진대요. 지도 속 열쇠는 파란색이래요.」 | 차가 출발하면 이야기도 출발합니다. 여기서부터 실제 차는 화면을 가리고 소리만 나옵니다. |
| 5 | 「와이퍼 켜기」 | (쓱싹 소리) 「쓱싹쓱싹! 와이퍼처럼 지도에 묻은 물방울을 닦았더니 글씨가 다시 보여요.」 → 「보물 상자 열쇠는 파란색일까요, 빨간색일까요?」 | 운전자가 켠 와이퍼를 앱이 읽어서 사건으로 만듭니다. 앱이 와이퍼를 켜지는 않습니다. |
| 6 | 화면 보기 「1번 · 파란색」 | 「맞아요, 파란색! 열쇠로 보물 지도 조각을 꺼냈어요.」 → 「대장님, 가는 길에 갈림길이 있대요. 갈림길 보물 표시는 별 모양이래요.」 | 실제로는 아이가 「1번」이라고 말로 답합니다. 오늘은 마이크 대신 화면으로 고릅니다. 틀려도 혼내지 않고 정답을 알려 준 뒤 같은 보물을 줍니다. |
| 7 | 「벨트 풀기」 → 「벨트 매기」 | 풀면 「벨트를 매면 계속할 수 있어요.」 매면 이어짐 | 벨트를 풀면 이야기가 멈추고, 다시 매야 이어집니다. |
| 8 | 「갈림길 통과」 | 「반짝! 갈림길 보물 표시가 나타났어요.」 → 「갈림길 보물 표시는 별 모양일까요, 하트 모양일까요?」 | 내비가 알려 주는 갈림길을 지나면 사건이 됩니다. |
| 9 | 보기 「1번 · 별」 | 「맞아요, 별 모양이에요! 갈림길 보물 조각을 찾았어요.」 → 「대장님, 다음 보물은 천안 근처에 숨어 있대요. 가까워지면 알려 줄게요.」 | |
| 10 | 「천안 근처」 | 「천안 근처에 왔어요! 천안에는 … 독립기념관이 있어요. 1987년 8월 15일에 문을 열었어요.」 → 「독립기념관이 문을 연 날은 8월 15일일까요, 3월 1일일까요?」 | 지나가는 도시마다 그 지역 이야기가 열립니다. 실제로는 위치가 들어오면 열리고, 시연에서는 버튼으로 넣습니다. |
| 11 | 보기 「1번 · 8월 15일」 | 「맞아요, 8월 15일이에요! 독립 태극기 조각을 찾았어요.」 → 대구 브리핑 | |
| 12 | 「대구 근처」 → 보기 1번 | 「대구 근처에 왔어요! 1907년에 대구에서 국채보상운동이 시작됐어요…」 → 질문 → 「맞아요, 나라 빚을 갚자는 운동이에요! 나라 사랑 동전을 찾았어요.」 → 경주 브리핑 | (빠르게 넘긴다) |
| 13 | 「첨성대 근처」 → 보기 1번 | 「경주에 들어왔어요! 경주에는 옛날 신라 사람들이 별을 보던 첨성대가 있어요.」 → 「첨성대에서 별을 보던 사람들은 신라 사람들일까요, 조선 사람들일까요?」 → 「맞아요, 신라 사람들이에요! 첨성대 보물 조각을 찾았어요.」 | 보물 다섯 개를 다 찾았습니다. |
| 14 | 「도착」 → P | 결말 「오늘 찾은 보물 조각을 하나로 맞췄어요. 정말 멋진 탐험이었어요, 대장님!」 → 「경주에 도착했어요! 오늘 찾은 보물 조각을 모아 경주 보물 상자를 열었어요.」 → 사실 「첨성대는 별을 관측하려고 높이 쌓은 대예요…」 → 「탐험 끝! 오늘 모은 보물을 확인해 보세요.」 | 도착하면 이야기를 맺고, 출처를 확인한 사실 한 문장을 들려줍니다. 보물 화면은 차가 서 있을 때만 봅니다. |
| 15 (넣을 수 있으면) | P에서 「미니게임 놀이터」 → 재생 패널 D | 놀이터가 열렸다가 D에서 닫힘 | 화면 놀이는 P일 때만 열고, 기어를 바꾸면 바로 닫습니다. |

- 질문은 다 읽은 뒤에만 화면 보기가 눌린다. 읽는 중에 누르면 안 먹으니 질문이 끝나고 누른다.
- 화면 보기가 안 보이면 재생 패널 「답 : …」 버튼을 쓴다. 같은 화면 선택 신호를 보낸다.
- 시간이 모자라면 : 7번을 뺀다. 그래도 길면 11번 뒤 바로 「첨성대 근처」를 누른다. 앞 장소(대구)는 보물 없이 넘어간다. 8번은 빼면 안 된다. 임무가 순서대로라 갈림길을 끝내야 장소로 간다(신호가 없으면 3분 기다림).
- **제안 (팀 확인 전)** : 12번과 13번 사이에 「5분 남음」을 누르면 「경주에 거의 다 왔어요. 마지막 보물이 기다리고 있어요.」가 나온다(#38). 보물을 다 찾기 전에만 나오니 이 자리에만 넣을 수 있다. 약 5초 길어진다.

## 마무리 (25초)

> 정리하면, 벨트로 시작하고, 실제 차 신호와 지나가는 도시로 보물을 찾고, 도착하면 끝납니다.
>
> 운전자를 부르지 않고, 내비가 말하면 비켜 주며, 아이 목소리는 저장하지 않습니다.
>
> 지금은 경주, 부산, 안동, 서울 네 경로가 있고, 대사는 파일로 분리되어 있어 지역을 계속 늘릴 수 있습니다.

## 문제가 생기면

| 상황 | 할 일 | 말 |
|---|---|---|
| 앱이 멈춤 | 앱을 다시 켜고 1번부터 | 다시 시작하겠습니다. |
| 다시 켜도 안 됨 | 미리 녹화한 영상 재생 | 같은 흐름을 녹화 영상으로 보여 드리겠습니다. |
| 소리가 안 남 | 화면 음성 상자의 대사를 읽는다 | 소리가 나오지 않아 제가 읽겠습니다. |
| 장소 버튼을 눌러도 안 열림 | 앞 대사·질문이 끝났는지 본다. 장소는 앞 임무가 끝난 뒤 이어진다 | 앞 이야기가 끝나면 이어집니다. |
| 보기를 눌러도 안 먹음 | 질문을 다 읽었는지 본다. 그래도 안 되면 재생 패널 답 버튼 | |

## 예상 질문

| 질문 | 답 | 발표 전 확인 |
|---|---|---|
| 사내 해커톤 대상작(테일싱크)과 뭐가 다른가요? | 저희는 이야기를 뒷좌석 안전 습관의 도구로 씁니다. 벨트가 재생 버튼이고, 운전자는 부르지 않으며, 와이퍼·내비 갈림길·지나는 도시처럼 실제로 일어나는 일을 사건으로 씁니다. | 팀이 같은 답을 하기로 정하기 |
| 주행 중에 화면은요? | 차가 앱 화면을 가립니다. 소리는 끝까지 이어지는 것을 에뮬레이터에서 확인했습니다. 화면 놀이는 P에서만 엽니다. | 통합 앱에서 다시 확인(`main_integration.md`) |
| 진짜 차 신호인가요? | 시연은 재생 모드로 넣었습니다. 재생 모드와 실제 차 신호는 같은 입구로 엔진에 들어갑니다. 실제 위치·내비 안내 연결은 차에서 더 시험해야 합니다. | 콘솔 시험 결과 |
| 아이가 어떻게 답하나요? | 부모가 동의하면 아이가 「1번」처럼 말로 답합니다. 동의하지 않으면 듣기만 해도 이야기가 이어지고, 차가 서 있을 때는 화면으로도 고를 수 있습니다. | 실제 발화 인식 시험 |
| 아이 목소리를 저장하나요? | 저장하지 않습니다. 부모가 동의해야만 듣습니다. | 음성 코드가 규칙대로인지 |
| 신호를 못 읽는 차는요? | 와이퍼는 2분, 갈림길은 3분 뒤 저절로 열립니다. 위치를 못 읽는 차는 장소 임무가 10분 뒤 열립니다. 비가 안 오면 「오늘은 비가 안 와서…」로 이어 갑니다. | 됨 |
| 역사 내용은 맞나요? | 한국민족문화대백과사전과 유네스코 자료로 확인한 내용만 넣고 출처와 확인한 날을 파일에 적었습니다. | 됨 (`factSource`) |
| 와이퍼나 에어컨을 앱이 켜나요? | 켜지 않습니다. 운전자가 켠 것을 읽기만 합니다. | |
