# 신호 확인 앱

첫 시험 전용 앱이다. 공식 샘플에 없는 값이 에뮬레이터에서 실제로 오는지 본다. 제출 앱(`app`)과 따로 빌드하고, 제출 APK에 들어가지 않는다.

지금까지 확인한 것은 컴파일까지다. 에뮬레이터에서 돌려 본 적이 없다. 켜자마자 죽거나 값이 안 오면 그것도 결과이니 오류 문구를 그대로 적는다.

## 설치

에뮬레이터를 켠 상태에서 저장소 폴더에서 실행한다.

```
gradlew.bat :signalcheck:installDebug
```

앱 목록의 「KidQuest 신호 확인」을 연다. 허용 창이 뜨면 허용을 누른다.

## 보는 법

화면 아래에 시각, 항목, 값이 위로 쌓인다. 같은 기록을 터미널에서도 볼 수 있다.

```
adb logcat -s KQSignal
```

| 항목 | 할 일 | 볼 것 |
|---|---|---|
| 기어 | 콘솔 Gear Selection을 바꾼다 | `기어` 줄과 `AAOS 기어` 줄 중 무엇이 오나. 권한 오류 문구 |
| 기어 D 앱 유지 | 기어를 D로 둔다 | 앱이 계속 떠 있나, `주행 규제` 값이 바뀌나 |
| 주행 중 소리 | 기어 D에서 「TTS 말하기」를 누른다 | 소리가 나나, `TTS` 줄이 어디까지 오나 |
| 말 듣기 | 「말 듣기」를 누르고 어른이 「초록색」이라고 말한다 | `STT` 결과 줄. 아이 목소리로 시험하지 않는다 |
| 내비와 겹침 | 길 안내 중에 「포커스 요청」 뒤 「TTS 말하기」를 누른다 | `오디오 포커스` 줄(잃음, 잠깐 잃음, 줄이라고 함). 끝나면 돌아오나 |
| 뒷좌석 소리 | 「소리 구역 바꾸기」 뒤 「TTS 말하기」를 누른다 | 소리 나는 곳이 바뀌나 |
| 탑승, 벨트 | 콘솔 Seat Occupancy와 Telltales를 바꾼다 | `탑승 지원 범위`, `벨트 지원 범위`에 뒷좌석이 있나. `벨트`와 `벨트 경고` 줄이 오나 |
| 방향지시등, 와이퍼 | 콘솔 값을 바꾼다 | 줄이 찍히나 |
| 잔량, 실내 온도 | 콘솔 Battery SOC, Target Temperature를 바꾼다 | 줄이 찍히나 |
| 남은 시간, 회전, 도착 | NaviDevApp으로 경로를 넣고 「내비 값 읽기」를 시간 차를 두고 누른다 | 남은 시간이 바뀌나. 회전 안내에 터널, 톨게이트가 오나. `도착` 줄 |
| 위치, 근처 알림 | `adb emu geo fix 127.0276 37.4979`로 안에 넣고 밖으로 뺐다가 다시 넣는다 | `위치` 줄, `근처 알림`의 ENTER와 EXIT |
